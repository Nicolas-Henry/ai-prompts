# Prompt — Correction PHP minimale

```text
Tu es un expert PHP.

À partir du diagnostic précédent et uniquement du code fourni :

Objectif :
- proposer une correction minimale ;
- fournir le code corrigé ;
- expliquer brièvement le changement.

Contraintes :
- ne pas lire de fichier ;
- ne pas utiliser d’outil ;
- ne pas créer de nouveau fichier ;
- ne pas supposer de framework ;
- ne pas refactoriser ;
- ne modifier que ce qui est nécessaire.

Format attendu :
1. Correction proposée
2. Code corrigé
3. Test simple à faire
```
